# Mishwar — مِشوار

**A contemporary Saudi restaurant website for Riyadh.**
Bilingual (Arabic first, English second), fully responsive, and built from scratch with HTML, SCSS and vanilla JavaScript.

> نكهة تعرفها، بشكل ما قد شفته.
> *A familiar taste, like you’ve never seen it before.*

> **Disclaimer:** Mishwar is a fictional restaurant created as a portfolio concept project. It is not affiliated with a real restaurant or business. All addresses, phone numbers, email addresses and social handles are placeholders.

## Overview

Mishwar serves the food Saudis grew up on, including kabsa, jareesh, qursan, matazeez and saleeg. The dishes are cooked by the old rules and presented through a contemporary restaurant experience. The website had to carry the same idea: recognisably Saudi, warm and social, but never a heritage cliché or a generic restaurant theme.

The site covers everything a guest needs:

- **Home**: hero, brand intro, signature dishes, philosophy, the room, branches and a booking prompt.
- **Menu**: 37 dishes across five categories, with category and dietary filtering.
- **About**: the story, the ingredients and where they come from, Saudi regional roots, hospitality and a timeline.
- **Locations**: two branches with live open/closed status, a stylised Riyadh map, a coming-soon third branch and a "Good to know" FAQ.
- **Reservations**: a three-step booking flow with a live summary, a confirmation "ticket" and an `.ics` calendar export.
- **Contact**: a directory, contact form, branch details and social links.
- **Privacy policy**, a **404** page, sitemap, robots file, web manifest and Open Graph images.

## Features

- **Arabic-first bilingual build.** Arabic lives at `/` (`lang="ar" dir="rtl"`) and English at `/en/` (`lang="en" dir="ltr"`). Both are rendered at build time, with no client-side translation, no flash of the wrong language, and proper `hreflang` alternates. The language switch links to the equivalent page.
- **RTL composed rather than mirrored.**
  - Layouts use CSS logical properties throughout.
  - Directional icons flip in RTL, and Arabic gets its own line-heights, sizes and typefaces.
  - Arabic is never letter-spaced.
- **Live opening status.** Every branch shows whether it is open *now* and when it next opens or closes. This is calculated in Riyadh time (`Asia/Riyadh`), handles service that runs past midnight, and marks today's row in each hours table.
- **Menu filtering.**
  - Category chips with live counts, plus dietary toggles for vegetarian, gluten-free, spicy and signature.
  - Filter results are announced to screen readers, the category is synced to the URL hash, there is an empty state, and filtering works as progressive enhancement.
- **Reservation flow.**
  - Branch cards and a 14-day date picker.
  - Time slots generated from each branch's real hours, with past slots disabled.
  - A guest stepper, and a Saudi mobile field that formats as `+966 5X XXX XXXX` and accepts pasted `05…`, `+966…` and Arabic-Indic digits.
  - Specific bilingual validation, an error summary, a confirmation state, a reference code and an "Add to calendar" `.ics` file.
- **API-ready services.** `src/js/services/config.js` sets `apiBaseUrl: null`, which simulates bookings locally. Setting a URL makes the reservation and contact services POST documented JSON payloads to `/reservations` and `/messages`.
- **Structured data.** `Organization`, a `Restaurant` per branch with `openingHoursSpecification` and `geo`, a full `Menu` → `MenuSection` → `MenuItem` graph, plus `WebSite` and `ContactPage`.
- **Motion with restraint.**
  - Motion includes the hero entrance, clip-path image reveals, staggered text, gentle parallax, a pausable dish-name marquee and cross-document View Transitions.
  - All of it is switched off under `prefers-reduced-motion`.

## Tech stack

| Layer | Choice |
| --- | --- |
| Markup | Semantic HTML5, generated by a small static-site build |
| Styles | SCSS (Dart Sass modules), compiled to one CSS file |
| Scripts | Vanilla JavaScript ES modules; each page lazy-loads only the modules it uses |
| Build | A Node script with no framework (`scripts/build.mjs`) and a tagged-template renderer that escapes output |
| Images | `sharp` pipeline producing responsive WebP variants, a unified colour grade and placeholder colours |
| Fonts | Self-hosted woff2 subsets (Arabic + Latin) of three open-source typefaces |

There are only two development dependencies, `sass` and `sharp`, and no runtime dependencies.

```
│   ├── dev.mjs                # watch + rebuild + live-reload server
│   ├── serve.mjs              # zero-dependency static server with pretty URLs and 404s
│   └── optimize-images.mjs    # sharp pipeline → src/assets/images/*.webp + manifest
└── src/
    ├── data/                  # content that could come from a CMS/API
    │   ├── menu.js            # categories + 37 menu items (bilingual, prices, dietary, seasonal)
    │   ├── locations.js       # branches, addresses, coordinates, weekly hours
    │   ├── site.js            # brand, contact details, socials
    │   └── images.js          # alt text (ar/en) + photo credits
    ├── content/               # page copy, one file per page ({ ar, en } pairs)
    ├── i18n/ui.js             # shared interface strings (nav, buttons, labels)
    ├── templates/
    │   ├── lib/               # html renderer, routes, render context, SEO/JSON-LD
    │   ├── components/        # header, footer, picture, dish, branch card, form fields, map…
    │   ├── pages/             # one module per page: meta(), render(), jsonLd()
    │   └── layout.js          # document shell
    ├── scss/
    │   ├── abstracts/         # tokens, breakpoints, mixins (no CSS output)
    │   ├── base/              # fonts, custom properties, reset, typography, utilities, motion
    │   ├── components/        # buttons, wordmark, badges, cards, forms
    │   ├── layout/            # header, mobile nav, footer, page hero, reserve bar
    │   └── pages/             # page-specific composition
    ├── js/
    │   ├── main.js            # boots reveals + mounts [data-module] elements lazily
    │   ├── core/              # i18n, reveal observer, "today" highlighting
    │   ├── modules/           # header, nav overlay, open status, menu filter, forms, parallax…
    │   ├── forms/             # validation, phone formatting, date strip, announcer
    │   ├── services/          # reservation/contact services, API config, .ics generator
    │   └── utils/             # hours, formatting, map links (shared by build and browser)
    └── assets/                # images, fonts, icon sprite, favicon, OG overlays
```

Content is kept separate from presentation. Menu items, branches and copy are plain data modules, so replacing them with a CMS or API response only changes the data layer. The templates stay the same.

## Running locally

Requires **Node 20+**.

```bash
npm install
npm run dev        # build + watch + live reload → http://localhost:5173
```

Other scripts:

```bash
npm run build      # production build → dist/
npm run serve      # serve dist/ → http://localhost:4173
npm run images     # regenerate WebP variants from src/assets/images/_source/
```

`dist/` is a fully static site and can be deployed to any static host. Configure the host to serve `404.html` for unknown routes.

The full-resolution photo originals (`src/assets/images/_source/`) are git-ignored because of their size; the optimised WebP files are committed.

## Design philosophy

**Saudi, without the clichés.** No camels, dunes or gold-on-black. Saudi identity comes through in the details:

- **Palette.** Taken from Najdi architecture and the table: limewash *plaster*, *ink*, fired *clay*, a deep *date* brown and *saffron*.
- **The *tarma* triangle.** The small triangular openings on Najdi mud-brick parapets. It appears sparingly as the eyebrow marker, the wordmark accent, the serrated top edge of the hero photograph, the footer edge and the section dividers.
- **The route.** *Mishwar* means an outing, the drive you take together. Dotted route lines connect branches on the Riyadh map and wander off course on the 404 page.

**Typography built for Arabic first.**

- **Arabic display face: Reem Kufi.** A geometric Kufi with personality, set at generous line-heights.
- **Text face: Plex Sans Arabic.** Clean and highly legible in both scripts.
- **English display face: Fraunces.** A soft editorial serif whose italic carries the accent words that are set in clay colour in Arabic.
- **Bilingual names.** Each dish name appears with the other language beneath it, in that language's own typeface.

**Editorial, not templated.** The layouts are asymmetric and use a strong type scale and generous whitespace. Every menu category has its own composition, and photography gets a unified grade so images from different photographers sit together. Radii are restrained (6px photographs, pill-shaped controls) and shadows are kept minimal.

**Copy with a voice.** The Arabic is natural Saudi Arabic, with a light Najdi tone in brand lines and clear standard Arabic for information. The English carries the same meaning in its own words rather than as a literal translation.

## Accessibility

- **Structure.** Semantic landmarks, one `h1` per page, a logical heading hierarchy and a skip link.
- **Mobile navigation.** Built on `<dialog>`, which provides a real focus trap, Escape to close, an inert background, and focus returned to the toggle.
- **Keyboard and focus.** Visible `:focus-visible` rings that change colour on dark surfaces. Touch targets are at least 44px.
- **Forms.**
  - Every field has a label and a hint.
  - Errors are wired with `aria-invalid` and `aria-describedby`, an error summary appears, and focus moves to the first problem.
  - Status updates such as time-slot changes and filter counts are announced through polite live regions.
- **Motion.** `prefers-reduced-motion` is honoured everywhere. The marquee has a pause control (WCAG 2.2.2).
- **Contrast and images.**
  - Colour contrast meets WCAG AA; for example, clay on plaster is 4.9 : 1.
  - Every photograph has meaningful bilingual alt text, and decorative SVGs are hidden from assistive technology.
- **Without JavaScript.** Menu, forms and navigation still work (progressive enhancement).

## Performance

- **Images.** Responsive WebP `srcset`s from 480 to 2400px, with explicit `width` and `height` to avoid layout shift. A dominant-colour placeholder shows while each image loads, and everything below the fold is lazy-loaded.
- **Hero image.** Preloaded with `fetchpriority="high"`.
- **Fonts.**
  - Self-hosted woff2 split into Arabic and Latin subsets via `unicode-range`, with `font-display: swap`.
  - Only the two first-paint faces for the current language are preloaded.
- **JavaScript.** Native ES modules with no bundle and no framework. Each page downloads only the modules its markup declares with `data-module`.
- **CSS.** One compressed stylesheet, cache-busted with a content hash.
- **No third-party requests.** No map embeds, analytics or font CDNs.
